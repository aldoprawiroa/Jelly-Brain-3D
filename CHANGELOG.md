# Changelog

## v1.0.0 · 2026-11-17

Rilis publik pertama Jelly Brain 3D, playground soft-body di browser.

### Termasuk dalam rilis

- Aplikasi satu halaman dengan geometri otak prosedural dan simulasi jelly.
- Interaksi tarik, lempar, orbit, Poke, Toss, Zap, dan Reset.
- Empat preset: Raspberry, Zombie lime, Grape, dan Ghost clear.
- Pengaturan firmness dan damping, slow motion, wireframe, serta pause/resume.
- Ekspresi karakter, telemetry, dan efek suara Web Audio yang dapat diaktifkan.
- README berbahasa Indonesia dengan panduan cepat, kontrol, screenshot gameplay, cara menjalankan lokal, dan petunjuk GitHub Pages.

### Batasan

- Three.js dan font dimuat dari layanan eksternal; belum ada mode offline.
- Kelancaran bergantung pada GPU, WebGL, dan ukuran viewport.
- Pengujian browser dilakukan pada Chromium desktop; dukungan semua perangkat dan browser belum diverifikasi.
- `index.html` dipertahankan tanpa perubahan pada penyiapan rilis ini.
